# Go Healthy 🥦🏃‍♀️

**Live Site:** [https://go-healthy.vercel.app](https://go-healthy.vercel.app)

Go Healthy is a modern and responsive health and wellness web application landing page. It is designed to promote healthy living through online services such as workout plans, diet guidance, health tracking, and virtual consultations. Built with React and styled for both mobile and desktop devices, this project is perfect for fitness trainers, health startups, or wellness influencers.

---

## ✨ Features

- 🧘‍♂️ Clean and modern landing page UI
- 📱 Fully responsive design (mobile + desktop)
- 🏋️‍♀️ Fitness programs and health consultation sections
- 🍎 Diet and meal planning highlights
- 📊 Visual health tracking elements
- 🚀 Fast performance and smooth animations
- 🌐 Deployed on [Vercel](https://vercel.com)
